# Alura Tracker

## Descrição

O Alura Tracker é uma aplicação web desenvolvida para auxiliar no acompanhamento de tarefas e no controle de tempo dedicado a cada atividade.

Com ele, é possível registrar tarefas, utilizar um cronômetro para medir o tempo de execução e visualizar uma lista com as atividades já cronometradas. A aplicação também conta com alternância entre modo claro e modo escuro, proporcionando uma experiência mais agradável ao usuário.

## Funcionalidades

- Cadastro de tarefas com título
- Cronômetro para acompanhamento do tempo
- Salvamento das tarefas com o tempo registrado
- Listagem das tarefas cadastradas
- Alternância entre modo claro e modo escuro

## Tecnologias utilizadas

- Vue.js
- TypeScript
- HTML
- CSS
- Bulma

## Objetivo do projeto

Este projeto tem como objetivo praticar conceitos de componentização, comunicação entre componentes, manipulação de estado e estilização de interfaces em Vue.js com TypeScript.
